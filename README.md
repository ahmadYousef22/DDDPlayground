# Learning POC - SSO & RabbitMQ

This project is designed for learning and understanding:
1. **SSO (Single Sign-On)** - Authentication concepts and implementations
2. **RabbitMQ** - Message queue patterns and concepts

## Project Structure

```
LearningPOC/
├── LearningPOC.Web/              # Main web application
│   ├── Controllers/              # API controllers
│   ├── Services/                 # Business logic services
│   ├── Models/                   # Data models
│   └── Program.cs                # Application setup
├── Documentation/                # Study guides
│   ├── SSO_CONCEPTS.md           # SSO fundamentals
│   ├── AUTHENTICATION_FLOWS.md  # Authentication flow diagrams
│   └── RABBITMQ_CONCEPTS.md      # RabbitMQ fundamentals
└── README.md                      # This file
```

## Learning Path

### Phase 1: SSO/Authentication
1. Read `Documentation/SSO_CONCEPTS.md` - Understand SSO basics
2. Read `Documentation/AUTHENTICATION_FLOWS.md` - Understand flows
3. Implement JWT authentication (simple)
4. Implement OAuth 2.0 SSO
5. Implement SAML 2.0 SSO (basic)

### Phase 2: RabbitMQ
1. Read `Documentation/RABBITMQ_CONCEPTS.md` - Understand message queues
2. Implement basic producer/consumer
3. Implement common patterns

## Purpose

This is a learning project focused on **understanding concepts** rather than production-ready code.
